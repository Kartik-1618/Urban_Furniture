## Description

The **Urban Furniture Accounting System** is a comprehensive, full-stack financial management application built for a furniture retail business. It digitalizes the entire accounting workflow — from master data management (contacts, products, chart of accounts) to complex financial reporting (Balance Sheet, P&L, Budget Analysis).

The system enforces **double-entry accounting principles**, ensures **role-based access control (RBAC)**, and delivers **real-time financial insights** — replacing manual spreadsheet-based processes with an integrated, auditable, and scalable digital platform.

## Core Features

### 📋 Master Data Management
- **Contact Master** — Manage Customers and Vendors with full profile details (name, type, email, address).
- **Product Master** — Catalog of goods and services with sales price, cost, and category.
- **Chart of Accounts (CoA)** — Define financial buckets (Asset, Liability, Expense, Income, Capital) that back every transaction.
- **Journal Master** — Categorize transactions by type (Sales, Purchase, Bank, Cash).

### 🛒 Purchase Cycle (Vendor Flow)
- Create **Purchase Orders (PO)** linked to vendors and products.
- Convert PO to **Vendor Bill** → auto-creates Journal Entry (Debit: Purchase Expense, Credit: Accounts Payable).
- Register **Payments** against bills → auto-creates Journal Entry (Debit: Accounts Payable, Credit: Cash/Bank).

### 💰 Sales Cycle (Customer Flow)
- Create **Sales Orders (SO)** with products, quantities, and tax calculation.
- Convert SO to **Customer Invoice** → auto-creates Journal Entry (Debit: Accounts Receivable, Credit: Sales Income).
- Record **Receipts** against invoices → auto-creates Journal Entry (Debit: Cash/Bank, Credit: Accounts Receivable).

### 📓 Manual Journal Entries
- Directly post debit/credit entries for adjustments, depreciation, or ad-hoc transactions.
- System enforces Total Debits = Total Credits before saving.

### 📊 Reporting & Analytics
- **Balance Sheet** — Real-time Assets = Liabilities + Equity view.
- **Profit & Loss (P&L)** — Income vs. Expense summary over a period.
- **Budget Report** — Compare planned budget vs. actual General Ledger figures per analytic account.
- **Analytic Accounts** — Group income/expenses by department, project, or store segment.

### 🔐 Security & Access Control
- Role-Based Access Control: **Admin**, **Accountant (Invoicing User)**, **Customer**.
- Customers can only view their own invoices and make payments.
- JWT-based secure authentication.

## Setup Instructions

### Prerequisites
- [Node.js 18+](https://nodejs.org/)
- [Python 3.11+](https://www.python.org/)
- [PostgreSQL 15+](https://www.postgresql.org/)
- [Docker & Docker Compose](https://www.docker.com/) *(optional but recommended)*

---

### Option A: Run with Docker Compose (Recommended)

```bash
# 1. Clone the repository
git clone https://github.com/Kartik-1618/Urban_Furniture.git
cd Urban_Furniture

# 2. Copy and configure environment variables
cp .env.example .env
# Edit .env with your values

# 3. Build and start all services
docker-compose up --build

# 4. Apply database migrations
docker-compose exec backend alembic upgrade head

# 5. Access the application
# Frontend: http://localhost:3000
# Backend API: http://localhost:8000
# API Docs: http://localhost:8000/docs
```

---

### Option B: Manual Setup

#### Backend (FastAPI)

```bash
# 1. Navigate to backend directory
cd backend

# 2. Create and activate virtual environment
python -m venv venv

# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Copy environment file
cp ../.env.example .env
# Edit .env with your DATABASE_URL and other secrets

# 5. Run database migrations
alembic upgrade head

# 6. Start the development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# API available at: http://localhost:8000
# Swagger docs at:  http://localhost:8000/docs
```

#### Frontend (Next.js)

```bash
# 1. Navigate to frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Copy environment file
cp ../.env.example .env.local
# Set NEXT_PUBLIC_API_URL=http://localhost:8000

# 4. Start the development server
npm run dev

# Frontend available at: http://localhost:3000
```

## Environment Variables

Copy `.env.example` to `.env` and fill in the values:

```env
# ── Database ──────────────────────────────────────────
DATABASE_URL=postgresql://user:password@localhost:5432/urban_furniture_db

# ── Authentication ────────────────────────────────────
JWT_SECRET=your-super-secret-key-change-this-in-production
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60

# ── Backend ───────────────────────────────────────────
BACKEND_HOST=0.0.0.0
BACKEND_PORT=8000
DEBUG=True

# ── Frontend ──────────────────────────────────────────
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_APP_NAME=Urban Furniture Accounting System

# ── Database (Docker) ─────────────────────────────────
POSTGRES_USER=urban_user
POSTGRES_PASSWORD=urban_password
POSTGRES_DB=urban_furniture_db
```
